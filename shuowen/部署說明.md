# 《說文解圖》2026 臺灣閱讀節限定版

此目錄必須放到 GitHub Pages 專案的 `reading-festival/shuowen/`。其中 `index.html` 為二選一活動入口。`room/` 和 `child/` 分別複製自已上傳的《陋室銘》與《兒時記趣》正式版本，圖片、音樂與原始答題／排序／速度／Combo 計分方式保留。

## 唯一要執行的 Supabase SQL

只執行 `reading-festival-shuowen-ONLY.sql` 這**一個檔案**，在既有 Supabase 專案的 SQL Editor 執行。請勿在 Supabase 執行 HTML、ZIP，也不要更動正式版任何 SQL。

## 部署

1. 解壓本 ZIP，將最內層 `reading-festival/shuowen/` 完整複製到 GitHub Pages 儲存庫對應路徑；如果目前 repo 根目錄本身就是 `reading-festival`，則只放 `shuowen/`，以實際預定網址 `/reading-festival/shuowen/` 為準。
2. 確認存在 `shuowen/index.html`、`shuowen/room/index.html`、`shuowen/child/index.html` 與其 image、music 資料夾。
3. 先執行上面唯一 SQL，再開啟入口，選一篇測試完成並檢查共用排行榜。**首次測試會真的新增活動測試成績**。
4. 接著在閱讀節總入口連結 `shuowen/index.html` 即可，無須更動《詩情畫意》。

## 活動版差異

- 兩篇共享獨立活動排行榜 `rf_sw_leaderboard`，上傳 `rf_sw_submit_score`，不使用原版 `room_leaderboard`、`child_leaderboard`。
- 完全採原始總分（不換算）；同一姓名只保留最好的那一場，打破最高分才更新篇章。
- 正式版書院學籍／文采／徽章／跨裝置同步已在活動副本停用，不會修改既有進度。
- 名字透過同分頁 sessionStorage 在入口和遊戲間傳遞；活動排名不需先建立雲端學籍。
- 雲端斷線會顯示本機紀錄，但不是活動的正式排行，需重新嘗試上傳。
- 公開匿名姓名排名不具身分驗證，參賽者勿填完整真名；前端分數無法防止刻意偽造。

## 測試項目

- 入口姓名→兩篇任選→配對／排序／回顧／結算→雲端上傳→排名→返回入口。
- 兩篇圖片完整、音樂按鈕播放、手機雙欄、重新開始不提前上傳。
- 同名玩家從兩篇分別上傳，只保留最高總分；原版排行榜與書院進度不受影響。

此為 **待部署實測版本**，尚未在使用者 Supabase 或正式 GitHub Pages 實際執行／測試。
